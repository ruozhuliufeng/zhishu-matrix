# ChatGPT Account Desk

macOS 14+ 的本地多账号 ChatGPT 会话管理器。每个账号使用独立的 WebKit 持久数据仓库，互不影响。账号资料（名称、邮箱、分组、订阅级别、到期日期、备注等）保存在 `~/Library/Application Support/ChatGPTAccountDesk/accounts.json`；密码由 ChatGPT 登录页面处理，应用不读取或保存密码。

## 构建与运行

```sh
zsh scripts/build-app.sh
open "build/ChatGPT Account Desk.app"
```

需要 macOS 14+ 和 Apple Command Line Tools。生成的 `.app` 位于 `build/`，采用本机临时签名，未经过 Apple 公证。

运行测试（页面识别脚本的 Node 测试 + 账号模型与解析器的 Objective-C 测试）：

```sh
zsh scripts/test.sh
```

仓库中的 `dist/ChatGPT-Account-Desk-v0.2.5-macos.zip` 是 0.2.5 版本的 macOS 应用包（Apple 芯片），解压后即可得到 `.app`；上一版本 `v0.2.4` 的应用包仍保留在 `dist/` 中。

图标母图为 `Resources/AppIcon-source.png`；构建脚本会生成多尺寸的 `Resources/AppIcon.icns` 并放入应用包。

## 界面

窗口采用三栏布局，两侧面板都可以折叠（`⌃⌘S` / `⌃⌘I`，或工具栏按钮）：

- **左侧账号栏**：搜索账号；设置分组后按分组显示。每行显示头像、订阅级别，以及到期提醒（7 天内到期为橙色、已过期为红色）或邮箱；头像上的绿点表示已登录。拖动账号可调整顺序，拖到其他分组下即移动到该分组。右键菜单提供打开、重命名、复制邮箱、移动到分组、导出、清除登录数据和删除。
- **中间区域**：工具栏的“浏览 / 管理”切换（`⌘1` / `⌘2`）。“浏览”显示当前账号的 ChatGPT 页面；“管理”显示账号总览。
- **右侧账号详情**：编辑名称、邮箱、分组、订阅级别、到期日期和备注，修改后自动保存。“续期”可把到期日顺延 1 个月、3 个月或 1 年（已过期则从今天算起）。下方显示创建时间、最近使用时间和登录状态。

## 账号管理

“管理”视图提供：

- 统计卡片：全部账号、付费订阅、7 天内到期、已过期，点击即可筛选。
- 搜索与筛选：按订阅级别、到期/登录状态和分组组合筛选。
- 账号表格：可按任意列排序，右键表头可隐藏或显示列，双击行在浏览器中打开。
- 批量操作：多选后可移动到分组、清除登录数据、导出所选或删除。
- 导入 / 导出：导出的 JSON 只包含账号资料，不包含密码、登录状态或访问令牌。导入时同一账号（相同 ID）会更新资料，文件中为空的字段保留本机数据；新增的账号需要重新登录。

7 天内到期和已过期的账号数量会显示在 Dock 图标角标上。

## 订阅与登录状态识别

登录 ChatGPT 后，应用会从左下角的账号入口自动识别当前订阅级别；也可以点击“从当前页面读取订阅”立即更新。在 ChatGPT 的账号设置中打开订阅详情后，应用还会尝试识别明确标示的到期日期。未识别到时保留已有数据。自动续费的“下次扣费日”不等于到期日，不会写入到期字段。

页面加载后，应用还会在页面内读取会话信息，只取回是否已登录、邮箱（仅在邮箱为空时填入）和套餐类型（仅在尚未获取订阅时填入），访问令牌不会离开页面。

ChatGPT 没有向此应用提供稳定的公开订阅信息接口，页面内容变化可能导致识别失效；此时可以手动填写。

## 客户端授权登录

Codex（CLI、IDE 插件）等支持“使用 ChatGPT 登录”的客户端会给出一个授权链接，例如 `https://auth.openai.com/oauth/authorize?…&redirect_uri=http://localhost:1455/auth/callback`。用系统浏览器打开时，登录的是浏览器当前的账号；在本应用中打开，则用指定的账号完成授权：

1. 在客户端发起登录，复制它给出的授权链接。
2. 选中账号，点击工具栏的授权按钮、右侧详情中的“打开授权链接…”或右键菜单中的同名项（`⇧⌘L`），粘贴链接后打开。可以直接粘贴包含链接的整段命令行输出，被终端折行的链接也能识别。
3. 链接会在一个独立窗口中打开，使用该账号在本机的登录状态。窗口顶部显示当前地址，便于确认是官方授权页面。
4. 授权后页面跳转回客户端的本机回调地址（或交给客户端注册的 URL scheme），窗口顶部会提示“授权结果已发送给客户端”，客户端随即完成登录。如果客户端已不再等待（例如已超时或已退出），会提示本机没有客户端在等待回调，此时需要在客户端重新生成授权链接。

### 复制 localhost 回调地址

授权跳转到 `http://localhost:…` 回调时，窗口顶部会显示完整的回调地址（例如 `http://localhost:1455/auth/callback?code=…&state=…`），点击“复制回调地址”即可复制。

客户端不在这台 Mac 上时（例如在服务器上运行 Codex，或需要把回调地址粘贴回去的工具），打开链接时勾选“只获取回调地址，不在本机打开”：授权后不会请求本机的 localhost，授权码不会发送给本机的任何程序，窗口直接显示回调地址供复制。该选项会记住上次的选择。即使没有勾选，本机连接回调失败时也同样可以复制。

回调地址包含一次性授权码，请只粘贴到发起登录的客户端，不要分享给他人。

授权链接可以指定：

- 每次打开时都可以修改链接；勾选“保存为此账号的授权链接”，或在右侧详情的“授权链接”中填写，即为该账号保存链接，之后打开时自动填入。
- 在“设置”（`⌘,`）中可以填写默认授权链接，账号没有单独设置时使用。
- 像 Codex 这样每次登录都会生成新链接（包含一次性的 state 和 code challenge）的客户端，不需要保存链接，打开时粘贴最新链接即可。

应用只负责在对应账号的会话中打开链接；回调地址只在授权窗口中显示和按需复制，不会保存。

## 会话与网页

- **查看当前会话**（`⇧⌘K`）：读取并查看 `https://chatgpt.com/api/auth/session` 的响应，面板支持复制。响应可能包含访问令牌，仅在当前面板中临时展示，不写入账号列表文件；复制后内容会留在系统剪贴板中，请谨慎分享。
- **清除登录数据**：退出该账号在本机的登录并清除 Cookie、缓存等网站数据，保留账号资料。
- **删除账号**：删除账号资料并清除该账号在本机的 WebKit 网站数据，不会删除线上 ChatGPT 账号。
- **释放后台账号页面**（“显示”菜单）：关闭当前账号以外已打开的页面以释放内存，再次打开时重新加载。
- 网页中可以上传文件；下载的文件保存到“下载”文件夹；ChatGPT 回答中的外部链接在默认浏览器中打开。页面加载失败时会在页面内显示错误和“重新加载”按钮。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 添加账号 | `⌘N` |
| 浏览 / 账号管理 | `⌘1` / `⌘2` |
| 搜索账号 | `⌘F` |
| 上一个 / 下一个账号 | `⌥⌘↑` / `⌥⌘↓` |
| 后退 / 前进 / 重新载入 | `⌘[` / `⌘]` / `⌘R` |
| ChatGPT 首页 | `⇧⌘H` |
| 查看当前会话 | `⇧⌘K` |
| 打开授权链接 | `⇧⌘L` |
| 导出全部账号资料 | `⇧⌘E` |
| 设置 | `⌘,` |
| 显示或隐藏侧边栏 / 账号详情 | `⌃⌘S` / `⌃⌘I` |

“导入账号资料”没有快捷键，因为 `⇧⌘I` 是 ChatGPT 网页“自定义指令”的快捷键。在账号列表或管理表格中，按 `Return` 打开账号，按 `Delete` 删除所选账号（会先确认）。网页输入框与账号资料字段支持 macOS 标准的撤销、重做、剪切、复制、粘贴和全选快捷键。

## 数据文件

`accounts.json` 是账号资料数组，旧版本的文件可以直接读取，未知字段会原样保留。启动时如果文件无法解析，应用会先把它备份为同目录下的 `accounts.unreadable-<时间>.json`，再以空列表启动。“文件 → 在访达中显示数据文件”可以打开所在目录。

这是独立的第三方容器，不是 OpenAI 官方客户端。部分第三方身份提供商可能拒绝嵌入式浏览器登录；这种限制由提供商决定。

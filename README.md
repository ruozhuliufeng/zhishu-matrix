# 智枢矩阵

macOS 14+ 的本地 ChatGPT 账号台账（0.2.6 及之前名为 ChatGPT Account Desk）：记录每个账号的订阅、供应商、付款方式与付款来源（卡尾号）、付款日期和金额，统一折合人民币统计费用，并可以用指定账号授权第三方应用的“使用 ChatGPT 登录”。每个账号使用独立的 WebKit 持久数据仓库，互不影响。账号资料（名称、邮箱、分组、订阅级别、到期日期、付款信息、备注等）保存在 `~/Library/Application Support/ChatGPTAccountDesk/accounts.json`；密码由 ChatGPT 登录页面处理，应用不读取或保存密码。

## 构建与运行

```sh
zsh scripts/build-app.sh
open "build/智枢矩阵.app"
```

需要 macOS 14+ 和 Apple Command Line Tools。生成的 `.app` 位于 `build/`，采用本机临时签名，未经过 Apple 公证。

运行测试（页面识别脚本的 Node 测试 + 账号模型与解析器的 Objective-C 测试）：

```sh
zsh scripts/test.sh
```

仓库中的 `dist/Zhishu-Matrix-v0.3.1-macos.zip` 是 0.3.1 版本的 macOS 应用包（Apple 芯片），解压后即可得到 `智枢矩阵.app`；之前版本的应用包仍保留在 `dist/` 中。

图标母图为 `Resources/AppIcon-source.png`；构建脚本会生成多尺寸的 `Resources/AppIcon.icns` 并放入应用包。

## 界面

窗口采用三栏布局，两侧面板都可以折叠（`⌃⌘S` / `⌃⌘I`，或工具栏按钮）：

- **左侧边栏**：随视图切换。“浏览”时是账号列表：搜索账号，设置分组后按分组显示，每行显示头像、订阅档位、额度或状态提醒，底部细条为每周额度剩余；拖动账号可调整顺序，拖到其他分组下即移动到该分组。“管理”时是导航：智能列表（全部账号、额度告急、即将到期、未登录、自动续费、资料不完整、重复邮箱）、各分组、各供应商、授权过的第三方应用和各标签，均显示账号数；右键分组、供应商、应用或标签可重命名或清除。
- **中间区域**：工具栏的“浏览 / 管理”切换（`⌘1` / `⌘2`）。“浏览”显示当前账号的 ChatGPT 页面（登录、授权、读取账单时使用）；“管理”显示所选列表中的账号。启动时默认打开“管理”，可在“设置 → 通用”中改为上次使用的视图。
- **右侧账号详情**：分为用量、资料、订阅、付款、网络、第三方授权、备注、记录几个可折叠的分区，折叠后标题右侧显示摘要；折叠状态按“浏览 / 管理”分别记住，管理视图默认展开用量、资料、订阅、付款和第三方授权。资料不完整时，详情顶部会列出缺少的项目，点击即可展开对应分区。修改后自动保存。“续期”可把到期日顺延 1 个月、3 个月或 1 年（已过期则从今天算起）。
- **工具栏**：后退 / 前进、浏览 / 管理切换、重新载入、首页，“账号”下拉菜单（当前账号的全部操作：授权登录、查看当前会话、读取账单、标签、分组、导出、清除登录数据、删除）和“刷新用量”按钮。

**统一的状态标记**：每个账号只显示当下最需要关注的一项状态，按优先级依次为：未登录、已过期、额度告急（任一窗口剩余不足 20%）、即将到期（7 天内且不自动续费）、读取失败，最后是灰色的“资料缺 N 项”。卡片、列表的“状态”列、详情顶部和菜单栏使用同样的颜色与图标，账号栏头像上的圆点同步变色。需要处理的账号数显示在 Dock 图标角标上。

右键菜单（账号栏、卡片、表格、日历通用）提供打开、重命名、复制邮箱、打开授权链接、查看当前会话、刷新用量与订阅、读取账单、在浏览中打开账单页、标签、移动到分组、设置供应商、设置付款信息（可多选批量设置）、导出、清除登录数据和删除。

## 账号管理

“管理”视图提供：

- **概览条**：顶部显示当前列表名称、账号数、付费与已登录数和用量更新时间；右侧的“额度告急 N”“即将到期 N”“资料不完整 N”和每月支出（折合人民币，未设汇率的币种标为“未换算”）可直接点击，前三项切换到对应列表（再点一次回到全部），每月支出打开费用报表。
- **搜索、筛选与排序**：搜索名称、邮箱、标签、备注、供应商、付款方式或卡尾号；按订阅档位筛选（可选 Pro 全部档位或某一档）；可按“需处理优先”、剩余额度、续费日期、月费（按人民币）、上次付款或名称排序。分组、供应商、标签和状态的筛选由左侧导航完成。
- **三种视图**：
  - 卡片：档位、状态标记、供应商与卡尾号、标签、5 小时与每周额度条和重置倒计时、续费信息与月费（有汇率时显示人民币），以及“打开 / 授权 / 刷新”按钮。
  - 列表：可按任意列排序（含状态、资料完整度、第三方授权、续费日期、月费（¥）、供应商、卡尾号），额度、付款方式、上次付款、原币月费、邮箱等列可在右键表头中显示。
  - 续费日历：按月显示续费与到期，自动续费的账号按月推算往后的续费日；顶部汇总本月续费笔数与折合人民币的金额。
  - 费用报表：见下方“费用报表”。
- **批量操作**：多选（`⌘` 点击）后可添加标签、移动到分组、刷新用量、读取账单、清除登录数据、导出所选或删除。批量操作只作用于当前列表中可见的账号。
- **“…”菜单**：导入 / 导出账号资料、导出续费日历（.ics）、导出付款记录（CSV）、刷新全部用量、后台读取全部账号账单、立即备份和备份设置。
- **导入 / 导出**：导出的 JSON 只包含账号资料（含标签、月费、续费设置、付款信息与付款记录和代理地址），不包含密码、登录状态、用量、访问令牌或代理密码。导入时同一账号（相同 ID）会更新资料，标签合并，文件中为空的字段保留本机数据；新增的账号需要重新登录。
- **重复邮箱**：多个账号使用同一邮箱（不区分大小写）时，账号详情顶部会提示，并出现“重复邮箱”列表，导入后也会提示。
- **导出续费日历**：生成 `.ics` 文件，可导入“日历”等应用。每个设置了日期的账号一个全天事件，自动续费的按月重复，并在前一天提醒；管理视图中多选账号时只导出所选账号。

## 付款信息与费用

每个账号在右侧详情的“付款”中记录：

- **供应商**：从哪里购买的订阅，可选 Google Play、iOS、世事宜AI、Bewild，也可以直接输入新的供应商。管理视图左侧会按供应商列出账号，右键账号可批量设置供应商。
- **付款方式**：信用卡、借记卡、支付宝、微信支付等，也可以输入其他方式。
- **付款来源（卡尾号）**：只保存卡号后 4 位；即使粘贴了完整卡号，也只会留下后 4 位。

**付款记录**：每次付款记一笔（“记一笔付款…”），包括日期、金额、币种、供应商、付款方式、卡尾号和备注，默认带入账号当前的付款信息；记录时可以勾选“同时把续费 / 到期日顺延 1 个月”。双击记录可修改，右键可删除。详情中汇总笔数、累计金额（折合人民币）和上次付款日期。“文件 → 导出付款记录（CSV）”导出全部账号的付款记录（含折合人民币），可用 Numbers 或 Excel 打开。

**记一笔付款**：自动续费的账号到了续费日、却没有对应的付款记录时（续费日前 3 天内或之后都没有记录），会：

- 发通知“××今天续费，记一笔付款？”，点通知或通知上的“记一笔”直接打开记账表单；
- 出现在菜单栏的“待记账”中，点击即可记账；
- 在卡片上的“记账”按钮、右键菜单和“账号”菜单的“记一笔付款…”中，日期默认就是这次续费日。

表单的金额按供应商价目表预填（没有时用账号月费），供应商、付款方式和卡尾号带入账号当前设置，确认即可。超过一周的漏记不再发通知，只出现在“待记账”和资料完整度中。

**供应商价目表**：在“设置 → 费用”中按供应商和档位填写月费（例如 世事宜AI 的 Pro 200 为 ¥1,599）。账号设置了供应商和档位后，月费与币种自动按价目表填写，记账时也按此预填；在账号详情中手动改过的月费不会被覆盖。修改价目表会立即更新使用价目表价格的账号。通过供应商购买的账号读取账单时，月费只取价目表，不取 ChatGPT 账单页上的金额。

**统一折合人民币**：在“设置 → 费用”中按“1 单位外币 = 多少人民币”手动填写汇率，账号和付款记录中用到的币种会自动列出。每月支出、续费日历、菜单栏、卡片和付款记录都按这些汇率折合人民币；没有填写汇率的币种不计入人民币合计，并提示“未设汇率”。

**从账单页读取**：读取账单时，如果订阅由 Apple 或 Google Play 管理，会自动把供应商填为 iOS 或 Google Play。对于没有填写供应商、直接在 ChatGPT 网页付款的账号，还会读取账单页上的卡尾号和“交易记录”中已支付的扣款，自动补到付款记录中（失败和已退款的不计）。通过 世事宜AI、Bewild 等供应商购买的账号，ChatGPT 账单页上的卡和扣款属于供应商，因此不会记入你的付款记录，也不会覆盖你填写的月费；档位和续费日期照常读取。

## 费用报表

管理视图的第四种视图“费用”（或点击顶部的每月支出），按付款记录统计实际支出，范围是左侧当前选中的列表：

- 按年查看，每月一根柱子，按供应商分色堆叠（颜色固定对应供应商），悬停显示当月明细，点击某个月份选中它；
- 按供应商、付款来源（付款方式与卡尾号）和账号分别汇总笔数与金额，双击账号可选中它；
- 选中月份的核对表：每个账号这个月预计何时扣款、预计金额（价目表或月费）和已记金额，状态分为已记、金额不同、未记、待扣款和计划外付款；双击“未记”“待扣款”的账号可以直接记一笔。

所有金额都折合人民币；没有汇率的币种不计入，并在顶部提示。

## 资料完整度

“资料不完整”列出缺少关键信息的账号，规则如下：

- 所有账号：邮箱、订阅级别；
- 付费账号还需要：续费 / 到期日期、月费（以及币种）、供应商、付款方式、付款记录；付款方式为信用卡、借记卡等银行卡时还需要卡尾号；
- 自动续费且已有付款记录的账号，超过 35 天没有新的付款记录时提示“近 35 天未记付款”，提醒补记最近一次扣款。

缺少的项目显示在账号详情顶部（点击展开对应分区）、列表的“资料”列和状态标记中。需要给很多账号补同样的供应商或付款方式时，在管理视图中多选后右键“批量设置付款信息…”，留空的项目保持原值。

## 订阅档位与标签

订阅档位包括 Free、Go、Plus、Pro（未知档位）、Pro 100、Pro 200、Pro 500、Business、Enterprise 和 Edu。用量接口只返回 “pro”，不会覆盖已知的 Pro 档位；档位以账单页的 “ChatGPT Pro 200” 为准。

标签和分组可以同时使用：每个账号只属于一个分组，但可以有多个标签（例如“主力”“备用”“风控中”）。在右侧详情中输入标签（回车或逗号分隔，自动补全已有标签），或在右键菜单的“标签”中勾选 / 取消，批量添加可用底部的“标签…”。

## 用量与订阅

“刷新用量”（`⇧⌘R`、工具栏、卡片上的“刷新”或菜单栏）会读取每个账号的：

- 5 小时与每周额度的剩余百分比和重置时间，以及额度余额；
- 当前周期结束日期（续费日或到期日）、是否自动续订、订阅档位；
- 登录状态，以及邮箱（仅在邮箱为空时填入）。

读取方式与网页一致：应用用该账号自己的会话在后台打开一个不可见的 chatgpt.com 小页面，在页面内调用 ChatGPT 自己使用的接口（`/backend-api/wham/usage`、`/backend-api/subscriptions`），只把解析结果带回应用；需要访问令牌时也只在页面内使用，不会保存。未登录的账号会标记为“未登录”。在“设置 → 用量与通知”中可设置自动刷新间隔（默认每天一次，可改为每 6 / 12 小时或关闭；从旧版本升级时，更频繁的设置会改为每天一次）。

**额度趋势与预估**：每次读取成功都会记录一次额度（保留 8 天），右侧详情的“用量”中显示近期剩余额度曲线；按近期消耗速度推算，如果额度会在重置前用完，会提示“按近期速度，每周额度约在 明天 06:20 用完（10月6日重置）”。

自动续费的账号在日期到来时续订，显示为“X 月 X 日自动续费”，不计入“即将到期”；取消续订的账号显示为“X 月 X 日到期”。

**读取账单（档位与月费）**：在右侧详情、右键菜单或“账号”菜单中使用，可多选批量读取，或用“后台读取全部账号账单”。应用在后台用该账号的会话打开 ChatGPT 的“设置 → 账单”，读取 “ChatGPT Pro 200” 这样的档位、“将在 2026年10月25日 自动续订”这样的续订日期，以及最近一笔扣款金额（例如 PHP 8,919.64）作为月费，全程不切换当前页面；未登录或读取失败的账号会汇总提示，也可以用“在浏览中打开账单页”在前台查看。只有确认是账单页时才会读取价格，“升级套餐”弹窗中的价格不会被当作月费。月费和币种也可以手动填写。

登录 ChatGPT 后，应用也会从左下角的账号入口识别订阅级别；ChatGPT 页面内容变化可能导致页面识别失效，此时可以手动填写。

## 菜单栏与通知

**菜单栏**：菜单栏图标列出需要处理的账号（未登录、已过期、额度告急、即将到期、读取失败）、30 天内的扣款与到期（自动续费的显示折合人民币的扣款金额）和每月支出；“全部账号”子菜单列出所有账号的状态与额度。点击账号即打开它；还可以刷新全部用量、打开账号管理、进入设置或锁定。有需要处理的账号时，图标旁显示数量。默认关闭主窗口后应用继续在菜单栏运行并隐藏程序坞图标，可在“设置 → 通用”中关闭菜单栏图标或改为关闭窗口即退出。

**通知**（“设置 → 用量与通知”，首次启动时系统会询问是否允许）：

- 额度告急：5 小时或每周额度剩余低于 20% 时提醒一次，并说明多久后重置；额度重置恢复后再提醒一次。
- 续费与到期：不自动续费的账号在到期前 3 天、前一天和当天提醒；自动续费的账号在续费前一天提醒，附带金额。
- 登录失效：曾经登录的账号被退出时提醒（自己“清除登录数据”不会提醒）。

每种提醒都可以单独关闭；同一件事只提醒一次，重启应用也不会重复。

## 应用锁

在“设置 → 安全”中开启后，打开应用时需要用 Touch ID 或 Mac 登录密码验证；还可以设置无操作或离开一段时间后自动锁定，以及屏幕锁定或电脑睡眠时立即锁定，也可以随时从菜单或菜单栏“立即锁定”。锁定时所有窗口隐藏，菜单命令不可用，已打开的页面、自动刷新和提醒照常运行。开启和关闭应用锁都需要验证。

## 备份与恢复

在“设置 → 备份”中：

- **本机备份**：账号资料变化后自动备份到数据文件夹的 `Backups/`（最多每小时一次，保留最近 30 份），也可以“立即备份”（文件菜单中也有）。
- **WebDAV**：填写服务器地址（例如坚果云 `https://dav.jianguoyun.com/dav/`、Nextcloud、群晖等）、用户名、密码和远程目录（默认 `ZhishuMatrix`，不存在时自动创建）。密码保存在“钥匙串”中。勾选后，自动备份会同时上传，远端保留最近 30 份；也可以“测试连接”“立即上传”。坚果云需要使用“第三方应用密码”。
- **恢复**：“从本机备份恢复…”或“从 WebDAV 恢复…”（从列表中选择一份），恢复会合并到当前账号列表：同一账号更新资料，备份中没有的本机账号保留；恢复前会先把当前列表备份一次。

备份内容与导出相同，只包含账号资料，不含密码、登录状态、访问令牌和代理密码。恢复后新增的账号需要重新登录。

## 网络代理

默认情况下，账号页面跟随 macOS 的系统代理设置（例如 Clash、Surge 开启的系统代理）。在“设置 → 网络”中可以填写默认代理，在右侧详情的“网络”中可以为单个账号单独设置，支持 `http://`、`https://` 和 `socks5://`，可带用户名和密码（`socks5://user:pass@127.0.0.1:1080`），也可以只写 `127.0.0.1:7890`。代理作用于该账号的页面、用量与账单读取以及授权窗口，修改后已打开的页面会重新载入。

“测试连接”会通过代理访问 chatgpt.com，显示 ChatGPT 看到的出口 IP 和地区；如果地区是中国大陆、香港或澳门，会提示 ChatGPT 不支持该地区，授权登录时会出现地区错误。

## 第三方授权登录

支持“使用 ChatGPT 登录”的第三方应用或网站会给出一个授权链接，例如 `https://auth.openai.com/oauth/authorize?…&redirect_uri=…`。用系统浏览器打开时，登录的是浏览器当前的账号；在本应用中打开，则用指定的账号完成授权：

1. 在第三方应用中发起登录，复制它给出的授权链接。
2. 选中账号，使用工具栏“账号”菜单、右侧详情中的“打开授权链接…”或右键菜单中的同名项（`⇧⌘L`），粘贴链接后打开。可以直接粘贴包含链接的整段文字，被折行的链接也能识别。
3. 链接会在一个独立窗口中打开，使用该账号在本机的登录状态。窗口顶部显示当前地址，便于确认是官方授权页面。
4. 授权后页面跳转回第三方的回调地址（或交给它注册的 URL scheme），窗口顶部会提示授权结果已发送。如果对方已不再等待（例如已超时），会提示没有应用在等待回调，此时需要让对方重新生成授权链接。

### 授权记录

每次用本应用授权成功（回调到本机、回调到第三方网站、交给第三方 App 处理，或勾选“只获取回调地址”后拿到回调地址）都会自动记到该账号的“第三方授权”中：同一个应用（按 client_id，没有时按回调地址识别）只占一条，记录首次和最近授权时间与次数，以及回调地址、申请的权限。新记录默认命名为“AI服务中心”（可在“设置 → 通用”中修改；留空则按回调地址命名，例如 `notion.so`、`本机应用（localhost:1455）` 或 App 名称），双击可改名、加备注；右键可标记为已撤销或删除记录。用户拒绝授权（回调带 `error=access_denied`）或回调失败的不会记录。

在别处授权过的应用可以用“手动添加…”补记。管理视图左侧的“第三方应用”列出授权过的应用，点开即可看到用了哪些账号；右键可以重命名，或把这些账号对它的授权都标记为已撤销。这里的“已撤销”只是本机记录，真正撤销需要在第三方应用或 ChatGPT 的设置中操作。

### 复制 localhost 回调地址

授权跳转到 `http://localhost:…` 回调时，窗口顶部会显示完整的回调地址（例如 `http://localhost:1455/auth/callback?code=…&state=…`），点击“复制回调地址”即可复制。

第三方应用不在这台 Mac 上时（例如在其他设备上，或需要把回调地址粘贴回去的工具），打开链接时勾选“只获取回调地址，不在本机打开”：授权后不会请求本机的 localhost，授权码不会发送给本机的任何程序，窗口直接显示回调地址供复制。该选项会记住上次的选择。即使没有勾选，本机连接回调失败时也同样可以复制。

回调地址包含一次性授权码，请只粘贴到发起登录的应用，不要分享给他人。

授权链接可以指定：

- 每次打开时都可以修改链接；勾选“保存为此账号的授权链接”，或在右侧详情的“授权链接”中填写，即为该账号保存链接，之后打开时自动填入。
- 在“设置”（`⌘,`）中可以填写默认授权链接，账号没有单独设置时使用。
- 每次登录都会生成新链接（包含一次性的 state 和 code challenge）的应用，不需要保存链接，打开时粘贴最新链接即可。

应用只负责在对应账号的会话中打开链接；回调地址只在授权窗口中显示和按需复制，不会保存。

## 会话与网页

- **查看当前会话**（`⇧⌘K`）：读取并查看 `https://chatgpt.com/api/auth/session` 的响应，面板支持复制。响应可能包含访问令牌，仅在当前面板中临时展示，不写入账号列表文件；复制后内容会留在系统剪贴板中，请谨慎分享。
- **清除登录数据**：退出该账号在本机的登录并清除 Cookie、缓存等网站数据，保留账号资料。
- **删除账号**：删除账号资料并清除该账号在本机的 WebKit 网站数据，不会删除线上 ChatGPT 账号。
- **释放后台账号页面**（“显示”菜单）：关闭当前账号以外已打开的页面以释放内存，再次打开时重新加载。超过设定时间（默认 30 分钟，可在“设置 → 通用”中修改或关闭）未使用的后台页面会自动释放。
- 网页默认以 Safari 浏览器身份打开（使用本机 Safari 的版本号）。否则 ChatGPT 会把内嵌网页识别为桌面客户端，只显示 Work 和 Codex，没有普通聊天，账单等设置也会要求前往网页版。可在“设置”中关闭，修改后已打开的账号页面会重新载入。
- 网页中可以上传文件；下载的文件保存到“下载”文件夹；ChatGPT 回答中的外部链接在默认浏览器中打开。页面加载失败时会在页面内显示错误和“重新加载”按钮。

## 数据文件

从 0.2.7 起应用改名为“智枢矩阵”，但应用标识（`local.zhishu.chatgpt-account-desk`）和数据目录保持不变，旧版本的账号资料和各账号的登录状态会直接沿用，无需重新登录。改名后请删除旧的 `ChatGPT Account Desk.app`，避免两个版本同时运行。

数据目录中还有 `usage-history.json`（近 8 天的额度记录，用于趋势和预估）和 `Backups/`（本机备份）。WebDAV 密码只保存在“钥匙串”中。

`accounts.json` 是账号资料数组，旧版本的文件可以直接读取，未知字段会原样保留。启动时如果文件无法解析，应用会先把它备份为同目录下的 `accounts.unreadable-<时间>.json`，再以空列表启动。“文件 → 在访达中显示数据文件”可以打开所在目录。

这是独立的第三方容器，不是 OpenAI 官方客户端。部分第三方身份提供商可能拒绝嵌入式浏览器登录；这种限制由提供商决定。
